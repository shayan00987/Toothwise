# Toothwise Dental Clinic Website

Responsive landing page for **Toothwise by Dr Osama Razzaq**, adapted from the supplied HTML.

## Project structure

- `index.html` — page content and layout
- `styles.css` — responsive image sizing, accessibility focus styles, reduced-motion support
- `script.js` — mobile navigation and appointment form behavior
- `assets/` — individually generated dental images, the supplied doctor portrait, and original oral-health illustration SVGs

## Run locally

Open `index.html` in a modern browser. The page uses Tailwind CDN, Google Fonts, and Font Awesome, so an internet connection is needed for those third-party styles and icons. The local image assets work offline.

## Functionality

- Responsive navigation and mobile menu
- Appointment form opens WhatsApp with the entered details for the clinic to confirm
- Phone, Instagram, map and section links retained from the supplied source

## Before publishing

- Test the appointment form on the target device/browser and confirm the clinic's WhatsApp number is correct.
- Verify all clinic claims, timings, address, and social links.
- For production, consider self-hosting external fonts/icons and Tailwind CSS.
